Privacy Policy

Last updated: September 20, 2026

This Privacy Policy explains how Java Daily Post Automation ("the App"), operated through the GitHub repository linkedinPost, handles information when it is used to publish content to a LinkedIn member profile.

1. Information We Use

The App may use a LinkedIn OAuth access token and the LinkedIn member identifier required to publish posts on behalf of the authorized LinkedIn member. These credentials are used only for the intended LinkedIn publishing workflow.

2. How Information Is Used

The App uses the authorized LinkedIn credentials to create posts on the authenticated member's LinkedIn profile. It does not sell, rent, or provide personal information to third parties.

3. Storage and Security

LinkedIn credentials used by the automation are intended to be stored as GitHub Actions encrypted secrets. The source repository is not intended to contain access tokens, client secrets, or other authentication credentials.

4. Data Retention

The App does not intentionally maintain a separate database of LinkedIn personal information. Generated post content and workflow metadata may be stored in the associated GitHub repository as part of the automation workflow.

5. Third-Party Services

The automation uses GitHub Actions and LinkedIn APIs. Their respective privacy practices and terms may also apply when those services are used.

6. User Control

The authorized LinkedIn member can stop the automation by disabling the GitHub Actions workflow or setting the project's automation control variable to false. LinkedIn authorization can also be revoked through LinkedIn's account and application settings.

7. Changes to This Policy

This Privacy Policy may be updated when the App's functionality or data handling changes. The latest version will be published at this URL.

8. Contact

Questions about this Privacy Policy can be raised through the project's GitHub repository: GitHub Repository.
