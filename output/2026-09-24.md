🎯 Your project discussion can decide how deep the interviewer goes into architecture.

🧠 PROJECT DISCUSSION / SENIOR-LEVEL

1. How did you review an architecture proposed by another team?
2. How did you verify that a performance fix actually worked?
3. What would happen if Redis became unavailable?
4. How did you separate business logic from infrastructure concerns?
5. How did you recover from a production incident?

🎯 FOLLOW-UP SCENARIO
6. How would you expose custom metrics using Micrometer?

📌 The interviewer may start with one question and keep drilling deeper. Practice the follow-up, not just the first answer.
