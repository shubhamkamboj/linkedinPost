🚨 One Java interview question can quickly turn into a discussion about performance, concurrency and design.

A simple practice routine:

1. What happens with a checked exception inside a @Transactional method?
2. How does @Transactional work internally?
3. What is a condition evaluation report and how can it help debugging?
4. What happens if two beans have the same type and neither is @Primary?
5. How would you cache method results with multiple parameters?

Now explain this one with a real production example:
6. What is a covering index?

📌 Practice answering these without looking at notes. Then challenge yourself with the next 'why?' question.
